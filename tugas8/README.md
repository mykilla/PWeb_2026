# Pendaftaran Siswa Baru - SMK Coding

Project PHP Native + MySQL untuk latihan CRUD pendaftaran siswa.

## Kebutuhan
- Laragon dengan Apache, PHP, dan MySQL
- Browser
- VS Code

## Instalasi
1. Letakkan folder `pendaftaran-siswa` di `C:\laragon\www`.
2. Jalankan Apache dan MySQL melalui Laragon.
3. Buka HeidiSQL atau phpMyAdmin, lalu jalankan isi file `database.sql`.
4. Periksa pengaturan koneksi di `config/database.php`. Default Laragon umumnya menggunakan user `root` dan password kosong, tetapi sesuaikan jika konfigurasi lokalmu berbeda.
5. Buka `http://localhost/pendaftaran-siswa/`.

## Catatan
Halaman daftar dan fitur edit/hapus pada project awal ini belum dilindungi login. Gunakan untuk latihan lokal, bukan untuk dipasang langsung ke internet.
